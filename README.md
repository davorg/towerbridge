# Tower Bridge Lifts

Stuff to create a data feed containing details of forthcoming Tower Bridge
lifts.

You can see the output at [towerbridge.dave.org.uk](https://towerbridge.dave.org.uk).
But the important bits are the machine-readable versions:

* [JSON](https://towerbridge.dave.org.uk/towerbridge.json)
* [ICS](https://towerbridge.dave.org.uk/towerbridge.ics)
